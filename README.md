## 🔷 Project Overview

**Daily Data Reporter AI** is a fully automated n8n workflow that runs every 24 hours — collecting data, generating AI-powered summaries, sending reports to the admin, and automatically replying to users.

```
⏰ Schedule → 📥 Collect Data → 🧠 AI Summary → 📧 Admin Report + User Reply
```

No manual work. No missed reports. Every day, on time.

---

## 🚀 Features

| Feature | Description |
|---|---|
| ⏰ **Automatic Daily Trigger** | Runs every 24 hours on a fixed schedule — zero manual activation |
| 📥 **Auto Data Collection** | Collects and filters data automatically |
| 📊 **Data Aggregation** | Aggregates all daily information into structured format |
| 🧠 **AI Summary Generation** | AI model generates clean, readable daily summaries |
| 📧 **Admin Daily Report** | Admin receives a complete report automatically every day |
| 💬 **Auto User Email Reply** | Automatically replies to users if their email is available |

---

## ⚙️ Workflow Overview

1. Trigger runs every 24 hours
2. Data is collected and filtered
3. Information is aggregated
4. AI generates a summary
5. Admin receives a report
6. Users receive automatic email responses

## 🚀 How To Use

### Prerequisites
- ✅ [n8n](https://n8n.io) instance (self-hosted or cloud)
- ✅ Email account (Gmail / SMTP)
- ✅ AI model API key

### Setup Steps

```bash
# 1. Clone this repository
git clone https://github.com/muhammadantor/daily-data-reporter-ai

# 2. Open n8n
# Go to: n8n → Workflows → Import
# Select: "Daily Data Reporter + Auto Responder System.json"

# 3. Configure credentials:
#    - Email account (Gmail OAuth2 or SMTP)
#    - AI model API key
#    - Your data source connection

# 4. Set your admin email address in the report node

# 5. Activate the workflow ✅
```

The workflow will automatically run every 24 hours and send your daily report.
